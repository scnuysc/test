# 银行客户流失预测 - 完整解决方案

## 项目概述

这是一个端到端的机器学习解决方案，用于预测银行客户流失。该项目通过分析客户基本信息和交易行为数据，构建高精度的预测模型，目标是达到AUC > 0.9的性能要求。

## 主要特点

- ✅ **完整的机器学习流程**: 从数据探索到模型部署的全流程
- 🚀 **高性能模型**: 使用XGBoost、LightGBM、随机森林和Stacking集成
- 🔧 **丰富的特征工程**: 包含60+个交易和行为特征
- 📊 **详细的数据分析**: 深入的EDA和特征重要性分析
- 🎯 **业务导向**: 提供实用的客户流失预防建议

## 数据结构

### 1. 客户基本信息表 (market_train/test)
- `f1`: 性别 (1-男性, 2-女性)
- `f2`: 职业代码
- `f3`: 年龄
- `f4`: 最高学历 (0-9)
- `f5`: 月收入金额
- `f6`: 客户单位所属行业
- `f7`: 客户关系建立渠道
- `f11`: 开户日期
- `f14-f16`: 移动银行登录次数 (近1/3/6月)
- `f17-f20`: 存款和投资余额信息

### 2. 交易流水表 (risk_train/test)
通过优化的Hive SQL查询提取的特征包括：
- 交易统计特征 (次数、金额、频率)
- 渠道使用特征 (手机银行、网银等)
- 时间序列特征 (近期活跃度)
- 风险特征 (大额交易、资金流向)
